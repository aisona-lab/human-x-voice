# Human X Voice

Cursor skill for writing X (Twitter) posts and replies that sound like a tired engineer in Slack, not like a model summarizing a blog.

## What it does

Teaches the agent to:

- lead with opinion, not summary
- use sarcasm, humor, or annoyance when earned
- allow swearing when it sharpens the point
- ban AI tells (em dashes, arrow characters, bait, LinkedIn cadence)

## Install

1. Clone this repo
2. In Cursor: install as a local plugin / point at this folder, or wait for marketplace listing
3. Invoke with `/human-x-voice` or let the agent pick it when drafting X copy
